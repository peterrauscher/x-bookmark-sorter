BookmarX settings

Connect the filing system, tune Jev, and keep credentials local to this browser.

01

TypeSafe API key

Required for bookmark classification.

Get a key at console.typesafe.ai. It is stored only in this browser (chrome.storage.local) and sent to api.typesafe.ai when sorting.

02

X account

Authorize folder reads and bookmark filing.
